# Live female voice: Supertonic 3 F3 / F1

v0.6 uses the fixed female F3 (formal) or F1 (calm) preset from supertone-oss-archive/supertonic-3 for Turkish and English. Model: BigScience Open RAIL-M License. Inference helper code: MIT, Supertone Inc. Full licenses are included in `JARVIS.app/Contents/Resources/voice-runtime/MODEL-LICENSE` and `CODE-LICENSE`. Python package license metadata ships with the runtime. No voice cloning is performed. The original project is archived; assets are pinned locally rather than fetched during speech. macOS female voices remain a fallback.

Sources: https://github.com/supertone-oss-archive/supertonic and https://huggingface.co/supertone-oss-archive/supertonic-3

# Voice research examples

Chatterbox Multilingual is from Resemble AI; MLX conversion and runtime from MLX Audio / MLX Community. Both upstream projects are MIT licensed. The experimental runtime and weights are archived outside the distributed app; the old experiment is not used by live speech. The female conditioning reference was generated with the installed macOS Yelda voice; no real person or actor recording was used. Four-bit conversion and four inference steps are local experimental settings.

Sources:
- https://github.com/resemble-ai/chatterbox
- https://github.com/Blaizzy/mlx-audio
- https://huggingface.co/mlx-community/chatterbox-multilingual-v3
